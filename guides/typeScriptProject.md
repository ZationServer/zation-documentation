# TypeScript Project

The projects generated by the CLI are TypeScript projects. This chapter explains the build setup.

Below you can see the folders and files of a generated server project that are essential for this chapter.

+ src
+ dist
+ test
+ tsconfig.json
+ package.json

The `src` folder contains your project code written in TypeScript.
The TypeScript compiler (`tsc`) translates this code into JavaScript which can be executed with Node.js.
All compiler options can be found in the `tsconfig.json` file; you can read more about it [here](https://www.typescriptlang.org/docs/handbook/tsconfig-json.html).
The generated JavaScript code is stored in the `dist` folder.

?> Zation uses decorators (e.g. `@Controller.Config`, `@Register`, `@ObjectModel`). The options `experimentalDecorators` and `emitDecoratorMetadata` must stay enabled in the `tsconfig.json`.

## NPM Scripts

The generated `package.json` provides these scripts:

| Script | Description |
| --- | --- |
| `npm run build` | Deletes the `dist` folder and compiles the project with `tsc`. |
| `npm start` | Builds the project and starts the server (`node dist/index.js`). |
| `npm run check` | Builds the project and starts the server in check mode (`MODE=c`). The server only validates the configurations and components and exits. |
| `npm test` | Builds the project and runs the mocha tests in the `test` folder with `ts-node`. |

If you want to build automatically on every file change, you can run the TypeScript compiler in watch mode:

```bash
npx tsc --watch
```

## Launch Modes

The server reads the launch mode from the `MODE` environment variable (or the second parameter of the `launch` function):

| Mode | Value | Description |
| --- | --- | --- |
| Development | `d` (default) | Debug and launch debug logs are available. |
| Production | `p` | Debug logs are disabled. Use this mode on public servers. |
| Test | `t` | Used by the test helper `zation-assured`. |
| Check | `c` | Only checks the configurations and components, then exits. |

```bash
MODE=p node dist/index.js
```
